# Ramya Rai Portfolio Website

This is a responsive one-page portfolio website built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page content
- `styles.css` — visual design and responsive layout
- `script.js` — mobile navigation menu

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Publish it so you can add it to LinkedIn
One beginner-friendly option is GitHub Pages:
1. Sign in to GitHub or create an account.
2. Create a new public repository named `ramya-rai-portfolio`.
3. Upload `index.html`, `styles.css`, and `script.js` to the repository's root.
4. Open the repository's **Settings → Pages**.
5. Under build/deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. Your public URL will look like `https://YOUR-GITHUB-USERNAME.github.io/ramya-rai-portfolio/` (replace the username with your actual GitHub username).

## Add it to LinkedIn
On LinkedIn, open your profile → **Add profile section** → **Recommended** → **Add Featured**. Choose **Add a link** and paste your published portfolio URL. You can also add it to your Contact info or headline/About section.

## Before publishing
- Confirm the current role start date and any project status labels.
- Add a project repository/demo link only when you have a real public URL.
- Add certificate images only if you are comfortable sharing them publicly; hide your USN/roll number and other private details first.
- You can add your professional headshot to the hero section later if desired.
- This site intentionally does not invent GitHub links or claim unverified project metrics.
